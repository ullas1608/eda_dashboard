# Student Performance Exploratory Data Analysis

This project performs Exploratory Data Analysis (EDA) on a student performance dataset using Python. The analysis explores student demographics, study habits, attendance, parental background, and their relationship with academic performance.

## Project Overview

The goal of this project is to:

- Understand the structure of the student performance dataset
- Clean and prepare the data for analysis
- Analyze student demographics and academic factors
- Identify patterns and relationships between different variables
- Visualize important insights using charts and graphs

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains information about students and their academic performance. It may include features such as:

- Student age
- Gender
- Parental education
- Study time
- Attendance
- Previous scores
- Exam scores
- Extracurricular activities
- Sleep duration
- Internet access
- Academic performance
